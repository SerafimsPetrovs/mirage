# MIRAGE — стриминг ИИ-сериалов

> Что сделано, что осталось и известные ограничения — в [docs/STATUS.md](docs/STATUS.md).

Платформа в духе Netflix для контента, созданного нейросетями: вертикальные шорт-дорамы (1–3 мин) и большие горизонтальные сериалы. Монетизация — VIP-подписка + монеты за серии, студия для авторов, админка с модерацией. Интерфейс RU / EN.

## Быстрый старт

Требования: **Node.js 20.9+** (рекомендуется 22 LTS), npm.

```bash
npm install
cp .env.example .env          # затем задайте SESSION_SECRET
npx prisma migrate dev        # создаёт prisma/dev.db и наполняет демо-данными
npm run dev                   # http://localhost:3000
```

Повторно наполнить базу: `npm run db:seed` (очищает все таблицы).

## Возможности

**Зрителям**
- Главная: hero-карусель, «Продолжить просмотр», Топ-10, шорт-дорамы, большие сериалы, новинки, подбор по настроению
- **Поток** (`/feed`) — вертикальная лента со свайпом и автоплеем, как в TikTok
- Плеер: вертикальный (свайп и стрелки между сериями) и горизонтальный; автопереход к следующей серии, сохранение прогресса, лайки, комментарии, список серий
- Ambient-свечение вокруг плеера по цветам кадра; двойной тап — лайк с сердечком, удержание — скорость 2×
- Мгновенный поиск по **Ctrl+K** или «/», плавный переход постер → страница сериала
- Пейвол: первые N серий бесплатно, дальше — монеты за серию или VIP
- **«Как это сделано»** — нейросети и заметки автора о промптах для каждого сериала
- **«Что дальше?»** — голосования зрителей за развитие сюжета
- Ежедневный бонус с 7-дневной серией наград
- Каталог с фильтрами (формат, жанр, настроение, сортировка), поиск, полка, история, рейтинги
- Кошелёк с историей операций, пакеты монет, VIP-тарифы
- RU / EN, PWA-манифест

**Авторам** (`/studio`)
- **ИИ-генерация** (`/studio/generate`): промпт, стиль, формат, кредиты генерации, очередь с прогрессом, клип одной кнопкой становится серией. Пока демо-провайдер без нейросети — см. [docs/ai-generation.md](docs/ai-generation.md)
- Создание и редактирование сериала (RU/EN, жанры, настроения, нейросети, постер и обложка, цены)
- Загрузка видео с прогрессом (mp4/webm/mov до 500 МБ) или ссылка на внешний файл
- Отправка на модерацию, голосования для зрителей
- Статистика: просмотры, открытия, заработок (50% монет) и график за 14 дней

**Администраторам** (`/admin`)
- Метрики, выручка, топ сериалов
- Очередь модерации (одобрить / отклонить с причиной)
- Витрина (featured), снятие с публикации
- Пользователи: роли, начисление монет, блокировка
- Заявки авторов, модерация комментариев

## Стек

## Структура

```
prisma/              схема, миграции, сид демо-контента
media/demo/          демо-ролики (генерируются, отдаются только через /api/stream)
storage/             загрузки авторов (в .gitignore)
src/app/(site)/      страницы с шапкой и футером: главная, сериал, каталог, профиль, студия, админка
src/app/(immersive)/ полноэкранные: плеер /watch, лента /feed
src/app/(auth)/      вход и регистрация
src/app/actions/     server actions (auth, library, wallet, studio, admin, profile)
src/app/api/         stream (Range + проверка доступа), poster (генеративные SVG), media, upload
src/lib/             доступ, монеты, платежи, каталог, сессии, файлы
src/i18n/            словари RU/EN и хелперы
src/components/      UI, медиа-карточки, плеер, студия, админка
```

## Безопасность и деньги

- Доступ к серии решает только сервер (`src/lib/access.ts`); `/api/stream` перепроверяет его для каждого запроса. Ссылки на закрытые видео клиенту не отдаются.
- Баланс — кэш, источник правды — журнал `CoinTransaction`. Списание идёт условным `updateMany` в транзакции: баланс не уходит в минус, повторное открытие той же серии бесплатно. Двойной клик и гонки покрыты тестом.
- Заказы зачисляются идемпотентно (`fulfillOrder`).
- Пароли — bcrypt; сессии — в БД (хранится хеш токена), httpOnly cookie.
- Защита от открытых редиректов (`safePath`), обход путей в хранилище, `nosniff` для медиа.

## Платежи

По умолчанию включён **тестовый провайдер**: оплата проходит мгновенно, деньги не списываются. В продакшене он работает только при `ALLOW_MOCK_PAYMENTS=1`. Как подключить Stripe или ЮKassa — в [docs/payments.md](docs/payments.md).
