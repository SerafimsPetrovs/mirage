## Раздел 1. Главный экран, Live TV и плеер эфира

### 1.1 Первая секунда (Zero-Friction Autoplay)
- [x] `/` сразу играет прямой эфир активного канала (без витрины и без экрана выбора).
- [x] Старт muted (обход блокировки автоплея) + крупная пульсирующая кнопка «🔊 Включить звук» поверх плеера.
- [x] Пока звук выключен — внизу плеера бегут субтитры текущей дорожки.
- [x] 4 базовых канала, текущее переключение сохранить: 1 Абсурд, 2 Инопланетный NatGeo, 3 Dark/SCP, 4 Music/Chill.

Решения:
- `/` = шапка сайта + встроенный ТВ-плеер (высота экрана) + под ним каталог (ряды Видеотеки) и витрина ИИ-приложений.
  Экран-развилка «Видеотека / Эфир» убирается. `/tv/[slug]` остаётся полноэкранным «кинотеатром».
- Каналы: Chill сливается с Music (канал 4 «Music / Chill»), «Сериальный» выключается — первые серии сериалов идут
  на тематических каналах по жанрам (это и есть затравка из 1.3). «Сказки» (семейный режим) и «Ночной 18+» остаются
  как условные каналы.
- Субтитры: у ТВ-ролика поле `captions` (WebVTT или SRT, вставляется при загрузке). У ведущего субтитры = его текст.
  Без субтитров показывается подпись-заменитель («[музыка] Исполнитель — Трек», «[без слов]»). Распознавание речи
  в браузере из медиа-потока невозможно бесплатно — честно не выдумываем.

### 1.2 Кнопка «ℹ️ Инфо» и расписание
- [x] Сохранить «что сейчас / что дальше» (программа уже есть).
- [x] Кнопка ℹ️ рядом с названием передачи → поповер без остановки эфира: название шоу/вселенной + лор,
      автор (ссылка на профиль), список нейросетей, теги жанра, возрастной рейтинг.

Решения: поля ролика `lore`, `aiTools`, `tags`, `ageRating`, `seriesId`. Для серий — из сериала (описание, aiModels,
жанры, рейтинг, автор). Новая публичная страница автора `/u/[id]` (раньше не было).

### 1.3 Воронка «из эфира — в платный сериал»
- [x] Если сегмент привязан к сериалу (серия или ролик с `seriesId`) — кнопка в углу
      «🍿 Смотреть весь сериал целиком (без очереди) →», крупно на последних 15 секундах.
- [x] Переход на `/series/[slug]` (2-я, 3-я… за монеты или VIP).
- [x] Очевидный переход в полный каталог (сериалы, комиксы с озвучкой, ИИ-фильмы) — под плеером при скролле и в шапке.
- [x] Клики считаются (для аналитики автора, 5.3).

### 1.4 Адаптивный чат
- [x] Десктоп: колонка справа, в шапке чата «Свернуть». Плеер плавно растягивается; плавающая иконка чата возвращает колонку.
- [x] Телефон/планшет: никакого блока под видео. Как TikTok Live — полупрозрачный оверлей снизу слева без фона;
      сообщения всплывают снизу вверх, живут 4–5 с и растворяются. Тап «Написать» — выезжает строка ввода и история;
      закрыл — снова прозрачный исчезающий поток.

### 1.5 «⚡ Ворваться в эфир»
- [x] Акцентная кнопка под чатом (десктоп) / в нижней панели (телефон): фиксированная цена в монетах, идея/скрипт →
      очередь генерации → эфир для всех с плашкой «Спонсор эфира: @username». (Механика заказа уже есть — переименовать,
      переставить, плашку уточнить.)

## Раздел 2. Жёсткий логин-гейт через 60 секунд
- [x] Гость: счётчик фактического просмотра `guestWatchTimeSeconds` в localStorage + sessionStorage + cookie
      (берём максимум — F5/очистка одного хранилища не сбрасывает).
- [x] < 60 с — смотрит свободно (эфир и серии).
- [x] На 60-й секунде: `video.pause()`, размытие 16px, звук выключен, загрузка новых чанков остановлена (HLS `stopLoad`).
- [x] Незакрываемая модалка (нет крестика, не закрывается по фону и Esc): войти/создать аккаунт, обещание +50 бонусных монет.
- [x] После входа модалка исчезает, блюр снимается, эфир продолжается с текущего момента (серия — с той же секунды).

Решения: формы входа/регистрации прямо в модалке (без ухода со страницы). Маскот на модалке.
Ограничение честно описать в docs/security.md: это клиентский счётчик, злоумышленник может его сбросить — цель воронка, а не DRM.

## Раздел 4. Маскот-ведущий и эмоциональный глитч-движок (без LipSync)
### 4.1 Концепция
- [x] Сквозной ведущий всех каналов (лицо скрыто: противогаз/шлем/маска). Дизайн утвердят позже →
      архитектура «слот персонажа»: банк клипов можно заменить, не трогая код.
- [x] Используется: ведущий в эфире, бренд на логотипе/модалках (в т.ч. логин-гейт), алерты креаторам.
### 4.2 Движок
- [x] Банк клипов (БД + хранилище): IDLE 3–4, NEUTRAL_TALK 5–6, HYPE_EXCITED 4–5, ANGRY_RAGE 4–5, LAUGH_SARCASM 3–4,
      SHOCK_SCARED 3–4, GLITCH_TRANSITION 3–4 (0.2–0.3 с). Загрузка в админке.
- [x] `parseScriptToEmotionalTimeline(text)` — детерминированный парсер (RU+EN), без LLM: фразы по знакам и союзам;
      ANGRY (капс > 2 слов подряд, `?!`, `!!!`, словарь злости), HYPE (`!`, словарь успеха), LAUGH (словарь юмора),
      SHOCK (`...`, `???`, словарь мистики), иначе NEUTRAL_TALK, паузы — IDLE. Выход JSON `{phrase, emotion, durationMs}[]`.
- [x] `DynamicMascotPlayer`: идёт по таймлайну под звук (TTS), каждые 0.5–1.0 с и на пиках громкости
      (Web Audio AnalyserNode) меняет микро-клип внутри эмоции, иногда вставляет GLITCH на 0.2 с.

Решения:
- Пока банк пуст — встроенный векторный маскот «Mr. Static / Мистер Помеха» (репортёр в противогазе) с позами на каждую
  эмоцию и CSS-глитчем. Как только админ загрузит клипы эмоции — плеер берёт видео.
- Звук: если настроен `TTS_PROVIDER` (OpenAI-совместимый `/audio/speech`) — mp3 через Web Audio с «радио-фильтром
  противогаза» (полоса 300–3400 Гц + лёгкий перегруз) и AnalyserNode. Иначе — голос браузера (speechSynthesis):
  он не идёт через Web Audio, поэтому пики берём из событий границ слов `onboundary`.

## Раздел 5. Креаторы: общий пул, чарты дефицита, баунти (`/studio`)
### 5.1 Общий пул
- [x] Все авторы грузят ролики/серии/скетчи/озвученные комиксы/музыку в единый пул.
- [x] При загрузке: целевой канал + опционально сериал; формат и метаданные (описание, промпты, нейросети, субтитры…).
- [x] Из пула планировщик (и админы вручную) собирают сетку и наполняют каталог.
- [x] Инвайты: зрители регистрируются свободно; статус креатора — инвайт-код (5 инвайтов у каждого активного автора)
      или заявка на одобрение админом (заявка уже есть).
### 5.2 Чарты дефицита и баунти
- [x] Для каждого канала шкала заполненности буфера на 24 и 48 ч.
- [x] 🟢 > 80 % — «укомплектован», ставка x1.0; 🟡 40–80 % — «нужен свежак», +25 %; 🔴 < 40 % — 🔥 HOT BOUNTY.
- [x] В зелёные каналы грузить можно. Ролик в красный канал после одобрения модерацией → автоматическая Bounty-награда.
Решения: буфер = минуты одобренного **свежего** контента канала (ещё не показанного или показанного < 3 раз)
против цели канала (`bufferTargetMin`, по умолчанию 120 мин/сутки). Зона фиксируется в момент загрузки ролика.
Награда при одобрении: кредиты генерации 20 × множитель (x1 / x1.25 / x2), в красной зоне ещё +30 бонусных монет.
Админ может вручную поставить «🔥 Дефицит / x2» (6.2).
### 5.3 Кабинет автора
- [x] Единый реестр работ (сериалы и ролики) со статусами: на модерации; в очереди эфира (покажут сегодня в 21:15);
      в ротации ТВ (показано N раз); опубликовано в каталоге.
- [x] Календарь релизов: выход следующих серий по дням и часам (`Episode.publishAt`; до этого серия скрыта от зрителей).
- [x] Трекер задач/драфтов: запланированные эпизоды, заметки по сценарию, чек-лист готовности.
- [x] Аналитика: просмотры из эфира, клики «к полному сериалу» из эфира, монеты от скинов, лутки, приватных сцен.

## Раздел 6. Режиссёрский пульт (`/admin/live-control`)
### 6.1 Задержка эфира
- [x] Публичный поток = мастер-таймлайн − 120 с. Два монитора: «Мастер (будущее +2 мин)» и «Глазами зрителя».
- [x] 🚨 PANIC: ролик мгновенно вырезается из буфера до показа, сетка бесшовно сдвигается к следующему.
Решение: зрительское время не трогаем (опросы, викторины, пауза рекламы продолжают работать как есть), а мастер-монитор
показывает сетку на +120 с вперёд — это та же модель задержки без риска рассинхрона.
### 6.2 Очередь
- [x] Живая очередь Up Next на ближайшие часы; drag-and-drop порядка.
- [x] Вставить любой ролик пула или серию «следующим» (Play Next) или «прервать и включить сейчас» (Force Play Now).
- [x] Вручную «🔥 Дефицит / Баунти x2» на канал.
- [x] Бегущая строка / системный алерт поверх эфира у всех зрителей.
### 6.3 Живой суфлёр
- [x] Текст → режим: «PiP в углу текущего видео» или «Breaking News полноэкранно после текущего ролика».
- [x] Тон: авто (словарь) или принудительно: злой / хайповый / саркастичный / криповый.
- [x] «🔴 ПУСТИТЬ В ЭФИР» → TTS (или синтезатор с радио-фильтром) → `parseScriptToEmotionalTimeline` → маскот у всех зрителей.
