# MIRAGE TV — межпространственное телевидение (дизайн)

_2026-11-09. Утверждено пользователем в чате._

## Идея
MIRAGE становится в первую очередь **межпространственным телевидением** (как кабельное в «Рике и Морти»):
несколько круглосуточных каналов, у всех зрителей синхронно идёт один эфир без перемотки, общий чат,
зрители влияют на эфир за монеты. Платформа ИИ-сериалов («Видеотека») — второй раздел, работает как раньше.

## 1. Развилка на входе
- `/` — экран выбора: **«Видеотека»** или **«Эфир»**. Последний выбор запоминается в cookie `mirage_mode`
  (`library` | `tv`) и подсвечивается, Enter запускает его.
- Видеотека → нынешний сайт (главная переезжает на `/library`, остальные адреса не меняются).
- Эфир → переход ~2 с: погасание экрана, белый шум, глитч-трещина, «схлопывание» кинескопа, разворот в `/tv`.
  При `prefers-reduced-motion` — простое затухание.
- Прямые ссылки (`/series/…`, `/tv/…`) открываются без развилки. В обоих интерфейсах есть кнопка «переключиться».
- Логотип в шапке видеотеки ведёт на `/library`.

## 2. Каналы (`TvChannel`)
| № | slug | Канал | Наполнение |
|---|---|---|---|
| 1 | absurd | Абсурд | ТВ-ролики (скетчи, фейковая реклама) + комедийные серии |
| 2 | xenogeo | Инопланетный NatGeo | псевдодокументалки + sci-fi/fantasy серии |
| 3 | dark | Тёмный эфир | SCP/хоррор + horror/thriller/mystery серии |
| 4 | music | Музыкальный (2000-е) | клипы, ВИ-джей, «Топ-10 недели», SMS-строка |
| 5 | chill | Chill | визуальный арт, музыка |
| 6 | series | Сериальный | бесплатные серии каталога + «Смотреть продолжение» |
| 7 | storytime | Сказки | только в семейном режиме, только `isFamilySafe` |
| 18 | night | Ночной 18+ | только при включённом 18+ (`isAdultMode`) |

Ведущие только вымышленные. Названия и логотипы реальных телеканалов не используются.

## 3. Контент эфира
- **ТВ-ролики (`TvClip`)**: вид SHOW | BUMPER | AD | MUSIC, канал, видео, длительность (ffprobe при загрузке),
  статус модерации PENDING/APPROVED/REJECTED. Загружают авторы в `/studio/tv` и админ в `/admin/tv`.
- Пробелы заполняются **бесплатными сериями каталога** (`number <= freeEpisodes`, опубликованные, не 18+ — кроме
  ночного канала, на детском канале только `isFamilySafe`) по жанрам канала.

## 4. Сетка (`TvSlot`)
- Строится лениво на сутки (UTC) при первом запросе дня, одна транзакция; уникальный ключ `(channelId, startsAt)`
  защищает от дублей при гонке.
- Порядок — детерминированный перемешанный по seed = `channel.slug + day`.
- Типы слотов: CLIP | EPISODE | HOST (подводка 8 с) | BREAK (рекламная пауза ~каждые 15 мин) | CHART (музыкальный, раз в 3 ч).
- Если видео короче слота — плеер крутит его по кругу (демо-ролики короткие); смещение = `offset % videoDuration`.

## 5. Ведущий-шоураннер
- Один LLM-запрос на канал в сутки (лимит бесплатного OpenRouter): JSON-массив подводок RU/EN по списку передач.
- Нет LLM / ошибка → шаблоны из `tv-rules.ts` (в характере канала).
- На экране — карточка ведущего, текст печатается; опционально голос браузера (speechSynthesis), выключен по умолчанию.

## 6. Синхронный эфир
- `GET /api/tv/[slug]/now` → `{ serverNow, slot, offsetSec, next[5], ticker[] }`. Клиент корректирует часы по serverNow.
- Видео серий — через существующие `/api/stream` и `/api/hls` (все проверки доступа сохраняются);
  ТВ-роликов — `/api/tv/clip/[id]` (только APPROVED, проверка канала 18+/семейного).
- Перемотки нет. Звук, громкость, полноэкранный режим, переключение каналов (←/→, цифры, свайп).

## 7. Живой чат (`TvMessage`)
- Опрос раз в 3 с (`?after=`), последние 50 сообщений. Работает на SQLite и любом хостинге.
- Только для залогиненных, 6 сообщений/мин, ≤ 200 символов, ссылки запрещены, MINOR_RE блокирует.
- Жалоба → скрытие после 3 жалоб; админ удаляет. В семейном режиме чат скрыт.

## 8. SMS-строка (`TvTicker`) — музыкальный канал
- 10 монет, ≤ 80 символов, без ссылок, фильтр. Показ в бегущей строке 30 минут у всех зрителей.
- Деньги платформе. Админ может скрыть (без возврата — нарушение правил).

## 9. «Закажи дичь в эфир» (`TvOrder`)
- 100 монет (бонусные первыми), идея ≤ 300 символов, проверка `checkPrompt`.
- LLM дописывает промпт (или используется идея как есть), `GenerationJob` (cost 0) через mock/LTX.
- Статусы: GENERATING → REVIEW → APPROVED → AIRED | REJECTED | FAILED.
- Отклонено/упало → монеты возвращаются (как у камео — бонусными, ledger REFUND).
- Одобрено → создаётся `TvClip` (AD, sponsorName = ник) и занимает ближайшую BREAK-паузу канала
  (привязка при наступлении паузы, атомарно). Без заказов в паузе — промо видеотеки/собственные AD-ролики.
- Не больше 3 открытых заказов на пользователя.

## 10. Музыкальный канал
- «Топ-10 недели»: клипы MUSIC по лайкам за 7 дней (`TvClipLike`, один лайк на пользователя).
- CHART-слот: ведущий объявляет обратный отсчёт, затем клипы 10→1 с плашкой места.

## 11. Дизайн ТВ
Отдельный layout без шапки сайта: чёрный фон, развёртка (scanlines), виньетка, OSD-цифры канала
моноширинным шрифтом зелёным/белым как на старом ТВ, «пульт» снизу, программа справа (на телефоне — шторка).

## 12. Безопасность и тесты
- Чистая логика в `src/lib/tv-rules.ts` (сетка, текущий слот, фильтры, шаблоны) — unit-тесты.
- `src/lib/tv.ts` (БД) — db-тесты: построение дня идемпотентно, заказ списывает/возвращает, тикер списывает,
  чат-лимиты, видимость каналов (18+ → 404, семейный режим → только сказки).
- Новые причины ledger: `TV_ORDER`, `TV_TICKER`.
