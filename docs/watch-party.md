# Смотреть вместе (watch party)

`/party` — создать комнату или войти по коду; `/party/КОД` — сама комната (ссылка = приглашение).
Кнопки «Вместе» — под эфиром (рядом с «Заказать шоу») и на странице сериала.

## Что умеет комната

- **Эфир** — все смотрят один канал. Сетка вещания общая, поэтому синхронизация «бесплатная»: комната решает только, какой канал включён.
- **Серия из каталога** — синхронно: в комнате хранится `{ playing, positionSec, stateAt }`, каждый плеер подстраивается
  (перескок, если ушёл дальше чем на 1,5 с). Проверено в браузере: расхождение между двумя зрителями ~0,07 с.
  Доступ у каждого свой: если серия у друга закрыта — он видит «Открыть за N монет», бесплатного обхода пейволла нет.
- **Пульт** — у хоста; можно передать любому. Только у владельца пульта: канал, серия, пауза/перемотка, «Все готовы?».
- **«Все готовы?»** → каждый жмёт «Я готов» → «Старт для всех» → отсчёт 3-2-1 и одновременный старт.
- **Чат комнаты**, **реакции** (летят по экрану у всех), **моменты** (★ — отметка времени в чате).
- **Голосование** «Что дальше?» — любой участник запускает, итог подводит владелец пульта.
- **Еда на всех**: каждый пишет, что хочет (и цену, если знает) → общий список, итог и «кто сколько платит» (до цента,
  доставка делится поровну). Кто-то жмёт «Я заказываю в…» (Bolt Food, Wolt, Glovo, Uber Eats, Яндекс Еда), открывает
  приложение, копирует список в комментарий к заказу, ставит «когда привезут» → у всех таймер. «Курьер пришёл» —
  **серия встаёт на паузу у всех**.
- **Атмосфера** (кинозал / неон / уютно / космос), до 12 человек, выгнать участника (хост), выход передаёт комнату дальше.

Технически: опрос `/api/party/КОД` раз в ~2 с (он же «я здесь»), действия — один server action `partyOpAction`.
Код: `src/lib/party.ts`, правила — `src/lib/party-rules.ts` (тесты), UI — `src/components/party/*`.

## Bolt Food и другие доставки — честно

Встроить **оформление заказа прямо в MIRAGE** сейчас нельзя: у Bolt Food, Wolt, Glovo и Uber Eats нет публичного API
для заказа от имени покупателя — их API только для ресторанов (меню, заказы ресторана) и курьерской доставки
(Wolt Drive, Uber Direct — «привези мой товар», а не «закажи еду из ресторана»). Поэтому сейчас комната делает всё, кроме
самой оплаты: собирает заказ, считает доли, открывает приложение, показывает таймер и ставит паузу, когда еда приехала.

Что можно дальше (нужны договорённости, это работа владельца, не кода):

1. **Партнёрская программа / реферальные ссылки** — Bolt и Wolt дают промокоды и партнёрские ссылки для бизнеса:
   кнопка «Открыть Bolt Food» может вести по партнёрской ссылке → платформа получает комиссию. В коде — одна строка
   (`FOOD_SERVICES` в `party-rules.ts`).
2. **Партнёрство уровня интеграции** (как у стримингов с доставкой в отдельных странах) — Bolt Business / Wolt for Work
   имеют корпоративные API. Если они согласятся, можно сделать «оплатить весь заказ одной кнопкой» и статус курьера
   прямо в комнате вместо ручного «когда привезут».
3. **Свой партнёр-ресторан/сеть** (пицца для «киноночей») — у сетей пиццерий бывают открытые API заказа; это
   реалистичнее, чем Bolt, для первого запуска.

MIRAGE не берёт денег за еду и не хранит платёжные данные для неё — оплата всегда в приложении доставки.
