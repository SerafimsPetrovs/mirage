## Этап 1. Запуск для первых настоящих зрителей (обязательно)

Без этого сайт нельзя открывать людям с настоящими деньгами.

| # | Задача | Кто | Стоимость |
|---|--------|-----|-----------|
| 1 | **Хостинг и домен.** VPS (Hetzner / DigitalOcean, ~€5–10/мес) или Vercel + Postgres (Neon/Supabase, есть бесплатные тарифы). HTTPS, `APP_URL`, уникальный `SESSION_SECRET`, бэкапы БД и `storage/`. | 👤 аккаунт и оплата, 🤖 настройка | €0–10/мес |
| 2 | **SQLite → PostgreSQL.** Смена провайдера в Prisma, перенос миграций, проверка поиска. | 🤖 | — |
| 3 | **Настоящие платежи.** Stripe (Европа) для монет и VIP; webhook → `fulfillOrder`. Интерфейс `PaymentProvider` уже готов ([payments.md](payments.md)). | 👤 аккаунт Stripe, компания/ИП, 🤖 интеграция | % с платежа |
| 4 | **Решение по 18+.** Stripe запрещает откровенный контент. Варианты: запуск без 18+ (раздел выключается целиком) или отдельный adult-friendly провайдер (CCBill, Segpay) + настоящая проверка возраста. | 👤 решение | — |
| 5 | **Почта.** Resend (бесплатно до 3000 писем/мес): подтверждение email и сброс пароля уже готовы, нужен ключ и домен. | 👤 аккаунт и DNS, 🤖 проверка | €0 |
| 6 | **Юридические тексты.** Заполнить `[плейсхолдеры]` в `src/content/legal.ts`, показать юристу, убрать плашку «черновик». | 👤 | юрист |
| 7 | **Перевыпустить ключи** OpenRouter / DeepSeek / Ollama / Hugging Face (передавались в чате). | 👤 | €0 |
| 8 | **Обновить Node.js до 22 LTS** → обновить vitest до 4.x (закрывает предупреждения `npm audit` в инструментах разработки). | 👤 установка Node, 🤖 обновление | €0 |
| 9 | **Стартовый контент:** 10–20 сериалов хорошего качества (свои или от первых авторов). | 👤 + 🤖 генерация | время / генерация |

## Этап 5. Дальше

- Мобильное приложение: сначала PWA (установка на экран телефона), потом нативные (React Native / Capacitor).
- Настоящая рекламная сеть для «реклама за серию» (Google IMA на вебе, AdMob в приложении).
- Автоматическая модерация загружаемых видео и картинок (внешний сервис).
- Отчёт для родителей и лимит экранного времени в детском режиме; таймер сна на сервере.
- Аналитика для авторов по фансервису (выручка по скинам, сценам, чату).
- Больше языков интерфейса (испанский, португальский — большие рынки коротких драм).
