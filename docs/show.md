# «Тысяча голосов» — сериал, который пишет интернет

Флагман маркетинговой стратегии (см. [marketing.md](marketing.md)). Сериал на MIRAGE: `/series/thousand-voices`,
админка: `/admin/show`.

## Библия

**Жанр:** романтика + мистика, вертикальные серии 60–90 секунд, каждая заканчивается развилкой.

**Вера Ланская, 24** — бариста ночной кофейни «Полночь» на Патриарших. После аварии на мосту слышит в голове
тысячу голосов: они спорят, советуют, шутят и голосуют. **Голоса — это зрители.** Вера всегда делает то, что решило
большинство.

**Артём Воронцов, 31** — холодный наследник строительной империи. Был на мосту в ночь аварии и что-то скрывает.
**Лёва, 27** — уличный музыкант, лучший друг Веры, единственный, кто верит в голоса.
**Марина Воронцова, 29** — сестра Артёма, улыбается слишком широко.

**Тайна сезона:** авария не была случайной. Голоса слышат то, чего не слышит Вера.

**Почему это работает:** голосование встроено в сюжет — зритель буквально «голос в голове героини». Имена тех, кто
«попал в сериал», звучат как голоса («Голос Кати: не верь ему!») или мелькают на вывесках, в телефоне, в списке гостей.

**Правила:** все персонажи взрослые, без откровенных сцен (сериал для широкой аудитории, 16+).

## Вышедшие серии

1. **Тысяча голосов** — Вера слышит голоса впервые; в кофейню входит мужчина с моста. _Развилка: сказать, что узнала?_
2. **Двойной эспрессо** — правда в лицо; визитка с чужим именем. _Позвонить по номеру?_
3. **Номер без имени** — женский голос называет Веру так, как звала только мама. _Идти на мост одной?_
4. **Ночная репетиция** — написана ИИ по итогам голосования (Вера взяла Лёву), камео: Алиса, Кира.

## Ежедневный цикл (20–40 минут)

1. `/admin/show` → посмотреть итоги голосования (при желании «Закрыть сейчас»).
2. Одобрить имена в «Камео на проверке», подарить 1–2 камео людям из «Топ поддержки».
3. «Написать серию N с помощью ИИ» → поправить текст (сценарий, развилка, подпись). Не понравилось — «Переписать».
4. «Сгенерировать клипы» → через 1–2 минуты выбрать лучший клип → «Опубликовать серию».
   Открывается новое голосование на 24 часа, имена камео появляются в титрах серии.
5. Для соцсетей: скачать клип(ы), смонтировать 60–90 с (CapCut — бесплатно), наложить реплики из сценария,
   вставить «Скопировать подпись». В конце ролика — развилка: «🔥 — вариант A, ❄️ — вариант B».
6. Утром посчитать реакции в комментариях соцсетей и добавить их голосами в голосование на сайте (или просто
   учитывать при выборе в п.1).

## Генерация видео

- Сейчас: **LTX-Video** через бесплатный Hugging Face Space (`GEN_PROVIDER=ltx`). Без ключа, ~5 с ролик,
  простое качество, маленькая дневная квота. Бесплатный `HF_TOKEN` (huggingface.co → Settings → Access Tokens)
  увеличивает квоту.
- Лучше по качеству вручную (бесплатно, через сайты): Kling, Hailuo, Pika — по тем же `PROMPT:` из сценария.
- Дальше: своя видеокарта с ComfyUI + Wan 2.x (см. [ai-generation.md](ai-generation.md)).
